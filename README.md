# Sala de visores · terrenoIA

Almacén público de los visores 3D (gemelos de información) de **Ing. David Yepes Builes — terrenoIA · Cultiva inteligencia**.

- `catalogo.json`: la lista que lee la vitrina (título, grupo, vistas, peso y miniatura de cada visor).
- `<proyecto>/<vista>.html`: cada visor, tal cual se entregó.
- `miniaturas/`: imagen de cada proyecto para las tarjetas.

Para agregar un visor: copiar su HTML en una carpeta nueva, agregar su entrada en `catalogo.json` y su miniatura.
